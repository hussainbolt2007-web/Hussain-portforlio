Hussain Lakdawala — Portfolio Website

Files:
- index.html: website content and structure
- style.css: visual design and responsive layout

How to preview:
1. Keep index.html and style.css in the same folder.
2. Double-click index.html to open it in a browser.

How to publish with GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a public repository named hussain-portfolio.
3. Upload index.html and style.css to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for GitHub Pages to publish and copy the live URL.

Before submission:
- Check the live site on desktop and mobile.
- Confirm all experience figures and dates are accurate.
- Add the live website and repository URLs to the final assignment PDF.
